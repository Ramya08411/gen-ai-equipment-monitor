From sensor reading to a plain-language diagnosis

The system runs as five connected steps. A simulated circuit produces the readings, and each later step adds something to them.

  1. Simulate

    A Tinkercad Arduino circuit reads a TMP36 temperature sensor and two potentiometers that stand in for voltage and current.

  2. Store

    Readings are saved in a CSV file, replayed to a Flask API and kept in an SQLite database.

  3. Check

    The dashboard compares every reading with its safe range and marks it OK or out of range.

  4. Explain

    Google Gemini receives the latest readings and returns the status, causes, troubleshooting steps and maintenance advice.

  5. Show

    A Streamlit dashboard displays live values, trend charts, alerts and the AI diagnosis.

Four scenarios, four different faults

The data file contains a normal run and three faults. Safe ranges are 0–70 °C, 22–26 V and 0–6 A.

Good to know

The readings are simulated. They come from a circuit simulation and a recorded data file, not from live hardware.

This website is a showcase. The Python application runs on a local computer. The full source code is on GitHub.

The AI gives suggestions. Its answers help with troubleshooting but are not a certified engineering opinion.
